# LAB: S3 Replication Hands-on

S3 Cross-Region Replication (CRR) aur Same-Region Replication (SRR) production environments ke liye behad zaroori hain. Isse aapka data disaster recovery, compliance, ya low-latency ke liye automatic ek bucket se dusri bucket mein copy hota rehta hai.

S3 Replication ke dono tarike hote hain:
- CRR (Cross-Region Replication): Data ko ek desh/region se dusre desh/region mein copy karna (e.g., Mumbai se N. Virginia).
- SRR (Same-Region Replication): Data ko ek hi region ke andar do alag buckets mein copy karna (e.g., Mumbai ki Bucket A se Mumbai ki Bucket B mein).

Chaliye, dono tarikon ki ek complete master hands-on lab karte hain.

### Lab Prerequisites (Dono Tarikon Ke Liye)

Replication chalane ke liye do rules compulsory hain:
- Source aur Destination dono buckets mein Versioning ON honi chahiye.
- AWS ko data copy karne ke liye permission chahiye hoti hai, jiske liye ek IAM Role lagta hai (AWS ise rule banate waqt automatic bana deta hai).

<br>
<br>

### Part 1: CRR (Cross-Region Replication) Lab

Isme hum data ko aapki Mumbai region ki bucket se kisi dusre region (jaise N. Virginia) ki bucket mein automatic bhejenge.

**Step 1: Destination Bucket Banayein (Different Region)**:
- AWS S3 Console mein jayein aur Create bucket par click karein.
- Bucket name dalein: ```puneet-crr-destination-2026```.
- AWS Region: Is baar koi alag region chunein, jaise US East (N. Virginia) us-east-1.
- Bucket Versioning: Niche scroll karke ise Enable karein (Kyunki bina versioning replication nahi chalega).
- Baaki settings default chodhkar Create bucket par click kar dein.

<br>

**Step 2: Source Bucket Par Replication Rule Banayein**:
- Apni purani source bucket (```meri-bucket-puneet```) ke naam par click karke use open karein (Maan lete hain yeh Mumbai region mein hai).
- Upar diye gaye Management tab par click karein.
- Niche scroll karein, aapko Replication rules ka section dikhega. Uske right side mein Create replication rule button par click karein.
- Replication rule name: Dalein ```My-Cross-Region-Rule```.
- Status: Ensure karein ki yeh Enabled ho.
- Source bucket: Yahan do options honge. Hum Apply to all objects in the bucket select karenge (taaki saara data copy ho).

<br>

**Step 3: Destination Aur IAM Role Set Karein**:
- Destination: Niche scroll karke Choose a bucket in this account select karein.
- Bucket name: Browse par click karke jo bucket aapne Step 1 mein banayi thi (```puneet-crr-destination-2026```), use select kar lein.
- IAM role: Dropdown kholkar Create new role select karein. AWS background mein khud saari permissions ka JSON script taiyyar karke role bana dega.
- Sabse niche scroll karein aur Save par click kar dein.

<br>

**Step 4: Existing Objects Ka Option (Poochta Hai)**:
- Jaise hi aap save karenge, AWS ek pop-up dikhayega: "Replicate existing objects?"
- Iska matlab hai ki kya jo files bucket mein pehle se uploaded hain, unhe bhi copy karna hai?
- Lab ke liye aap No, do not replicate existing objects select karke Submit kar dein. (Yani ab se jo nayi file aayegi, sirf wahi copy hogi).

<br>
<br>

### Part 2: SRR (Same-Region Replication) Lab

Isme hum data ko ek hi region ke andar do alag buckets mein backup rakhne ke liye copy karenge.

**Step 1: Destination Bucket Banayein (Same Region)**:
- Create bucket par click karein.
- Bucket name dalein: ```puneet-srr-destination-2026```.
- AWS Region: Is baar bilkul wahi region chunein jo aapki original source bucket (meri-bucket-puneet) ka hai (e.g., Asia Pacific (Mumbai) ap-south-1).
- Bucket Versioning: Ise bhi Enable karein.
- Create bucket par click kar dein.

<br>

**Step 2: Source Bucket Par Dusra Rule Banayein**:
- Wapas apni original source bucket (```meri-bucket-puneet```) ke andar jayein.
- Management tab -> Replication rules -> Create replication rule par click karein.
- Replication rule name: Dalein ```My-Same-Region-Rule```.
- Source bucket: Phir se Apply to all objects in the bucket select karein.
- Destination: Browse karke is baar apni same region wali bucket (```puneet-srr-destination-2026```) ko select karein.
- IAM role: Dropdown se wahi role select kar sakte hain jo CRR ke waqt bana tha, ya fir se Create new role kar sakte hain.
- Sabse niche jaakar Save karein aur existing objects ko No karke submit kar dein.

Now, aapki source bucket par dono rules (CRR aur SRR) ek sath active ho chuke hain!

<br>
<br>

### Live Testing (Dono Tarike Check Karein)
- Apni main source bucket (```meri-bucket-puneet```) ke andar jayein.
- Upload par click karke apne computer se koi bhi nayi test file (jaise ```replication-test.txt```) upload kar dein.
- Upload hone ke baad exact 10-15 seconds wait karein (Kyunki replication background mein thoda sa samay leta hai).
- Check SRR: Apni same-region wali bucket (```puneet-srr-destination-2026```) kholkar dekhein, wahan aapki file automatic copy ho chuki hogi.
- Check CRR: Apni different-region wali bucket (```puneet-crr-destination-2026```) kholkar dekhein, wahan bhi aapki file automatic pahunch chuki hogi.
