# Byte-range Fetches

AWS S3 mein Byte-Range Fetches (jise hum generic networking mein Range Requests bhi kehte hain) ek aisa advanced data retrieval feature hai jo aapko ek poori file (object) download karne ke bajaye uske ek specific hisse (part/byte range) ko hi download karne ki suvidha deta hai.

S3 Byte-Range Fetches (jise Range Requests bhi kaha jata hai) Amazon S3 ka ek aisa advanced data retrieval feature hai jo aapko poori ki poori file download karne ke badle, us file ka ek chota sa specific hissa (byte segment) download karne ki permission deta hai.

Simple shabdon mein, agar aapke paas 10 GB ki ek badi video file S3 mein padi hai aur aapko sirf uske beech ke 5-minute ka clip dekhna hai ya sirf metadata read karna hai, to aap poori 10 GB file download nahi karenge. Aap S3 ko kahenge ki "Mujhe is file ka byte number 5000 se lekar byte number 9000 tak ka data de do." S3 sirf utna hi tukda aapko deliver karega. Isee ko Byte-Range Fetch kehte hain.

Agar aap poori 10 GB file download karenge, to aapka time, network bandwidth, aur AWS Data Transfer cost teeno barbaad honge.

Jaise Multi-part Upload badi files ko tukdon mein upload karne ke liye hota hai, thik vaise hi Byte-Range Fetches badi files ko tukdon mein download (fetch) karne ke liye hota hai. Iske liye HTTP request mein Range header ka use kiya jata hai.
