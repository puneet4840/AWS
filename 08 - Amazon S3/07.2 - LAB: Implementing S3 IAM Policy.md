# Implementing S3 IAM Policy

S3 IAM Policy ki ek real-world hands-on lab karte hain.

Is lab mein hum ek aisa naya user banayenge jise AWS Console ka access hoga. Phir hum ek custom IAM Policy banayenge jo us user ko hamari pehle se bani hui bucket (```meri-bucket-puneet```) ke andar ki files dekhne (List Objects) aur download karne (Get Object) ki permission degi, lekin woh file delete ya upload nahi kar payega.

<br>

### Lab Objective

Ek IAM User banana jise **Console login access** ho, ek Read-Only **IAM Policy** lagana, aur fir ek naye Incognito window mein us user se login karke live check karna ki woh kya kaam kar pa raha hai aur kya nahi.

<br>
<br>

### Step 1: IAM User Banayein (Console Access Ke Sath)

Sabse pehle hum ek aisa user banayenge jo browser se login kar sake.
- AWS Console mein upar search bar mein **IAM** search karke open karein.
- Left side ke menu mein **Users** par click karein.
- Top right mein **Create user** par click karein.
- User name dalein: ```console-test-user```.
- Yahan dhyan dein: Aapko "**Provide user access to the AWS Management Console - optional**" wale checkbox par tick (check) lagana hai.
- Jaise hi aap tick karenge, niche kuch options khulenge:
  - **Identity type**: An IAM user select karein.
  - **Console password**: Custom password select karein aur apna ek strong password rakh lein (jaise ```Puneet@123```).
  - **Users must create a new password at next sign-in**: Isko **Uncheck** kar dein (taaki lab ke dauran baar-baar password badalna na pade).
- Niche **Next** par click karein.
- **Permissions page** par abhi kuch select mat kariye (Hum apni custom policy lagayenge). Direct **Next** par click kariye.
- Review page par sabse niche jaakar **Create user** par click kar dein.

<br>
<br>

### Step 2: Login URL Aur Username/Password Sambhal Kar Rakhein

User bante hi aapke samne ek screen aayegi jisme user ki details hongi
- Wahan aapko **Console sign-in URL** dikhega (Yeh ek aisa link hota hai jisme aapka AWS Account ID hota hai, jaise: https://amazon.com).
- Is **Sign-in URL** ko copy karke kisi notepad mein rakh lijiye.
- Apna password aur username (```console-test-user```) bhi yaad rakhein.
- Ab niche **Return to users list** par click kar dein.

<br>
<br>

### Step 3: Custom IAM Policy Banayein (Using Visual Editor)

Ab hum wahi strict policy banayenge jo user ko sirf ek hi bucket dekhne degi.
- IAM Dashboard mein left side ke menu mein **Policies** par click karein.
- Top right mein **Create policy** par click karein.
- Jaise hi page khulega, aap Visual tab ke andar honge (jahan options hote hain).
- **Select a service**: Ek search bar dikhega, usme **S3** type karein aur niche aane wale S3 option par click kar dein.
- **Actions allowed**: Ab aapke samne permissions ki list khul jayegi. Hum yahan teeno permissions dhoondh kar tick lagayenge:
  - **List permissions**: Is dropdown ko kholein aur ```ListAllMyBuckets``` aur ```ListBucket``` ke samne wale checkbox par tick laga dein.
  - **Read permissions**: Is dropdown ko kholein aur thoda niche scroll karke ```GetObject``` ke samne wale checkbox par tick laga dein.
 
<br>
<br>

### Step 4: Bucket Aur Files Ka Naam Dalein (Resources)

Ab hum AWS ko batayenge ki ye permissions kis bucket par lagani hain. Niche aapko Resources ka section dikhega.
- **Resources** ke andar Specific wale radio button par click karein.
- Ab aapko do alag-alag options dikhenge jinhe configure karna zaroori hai: **bucket** aur **object**.

**A. Bucket Permission Set Karein**:
- List mein ```bucket``` ke aage likhe **Add ARN** par click karein.
- Ek pop-up window khulega. Wahan **Bucket name** wale box mein apni asli bucket ka naam likhein: ```meri-bucket-puneet```.

**B. Object Permission Set Karein**:
- Usi list mein ab ```object``` ke aage likhe **Add ARN** par click karein.
- Fir se pop-up khulega. **Bucket name** mein wahi naam dalein: ```meri-bucket-puneet```.
- Niche **Object name** wale box mein ek ```*``` (star/asterisk) bana dein. Iska matlab hai is bucket ke saare objects (files).
- **Add ARNs** button par click kar dein.

(Aap screen par dekh sakte hain ki AWS ne khud se dono ARNs generate kar diye hain, aapko khud type nahi karna pada).

<br>
<br>

### Step 4: Policy Ko Name Dein Aur Banayein

- Page ke sabse niche jayein aur **Next** button par click karein.
- **Policy name** wale box mein likhein: ```Console-S3-ReadOnly-Policy```.
- Description mein aap apni pehchan ke liye kuch bhi likh sakte hain (optional).
- Sabse niche jaakar **Create policy** par click kar dein.

**Success!** Aapki custom policy bina kisi JSON coding ke, sirf AWS ke options use karke tayyar ho chuki hai.

<br>

### Step 4.1: Agar JSON ke thorugh policy create karna chate hain to ye JSON code add karo.

- IAM Dashboard mein left side ke menu mein **Policies** par click karein.
- Top right mein **Create policy** par click karein.
- **JSON** wale tab par click karein.
- Jo pehle se likha hai use mita kar, niche wala code paste karein (Apna asli bucket name ```meri-bucket-puneet``` use karein):

```
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "AllowConsoleToSeeBucketList",
            "Effect": "Allow",
            "Action": [
                "s3:ListAllMyBuckets"
            ],
            "Resource": "*"
        },
        {
            "Sid": "AllowUserToSeeSpecificBucketContent",
            "Effect": "Allow",
            "Action": [
                "s3:ListBucket"
            ],
            "Resource": [
                "arn:aws:s3:::meri-bucket-puneet"
            ]
        },
        {
            "Sid": "AllowUserToDownloadFiles",
            "Effect": "Allow",
            "Action": [
                "s3:GetObject"
            ],
            "Resource": [
                "arn:aws:s3:::meri-bucket-puneet/*"
            ]
        }
    ]
}
```

Technical Note: Is baar maine code mein ek naya action joda hai: "s3:ListAllMyBuckets". Yeh console user ke liye zaroori hai. Agar yeh nahi lagayenge, toh jab user S3 dashboard kholega, toh use error dikhega aur woh hamari bucket tak pahunch hi nahi payega.

- Code paste karke **Next** par click karein.
- **Policy name** mein dalein: ```Console-S3-ReadOnly-Policy```.
- Sabse niche jaakar **Create policy** par click kar dein.

<br>
<br>

### Step 5: Policy Ko User Se Attach Karein

- IAM Dashboard mein left side se **Users** par click karein.
- Apne naye user ```console-test-user``` ke naam par click karein.
- Permissions tab mein right side mein **Add permissions** -> **Add permissions** par click karein.
- Teesre box "**Attach policies directly**" par click karein.
- Search bar mein apni policy search karein: ```Console-S3-ReadOnly-Policy``` aur uspar tick lagayein.
- **Next** aur fir **Add permissions** par click kar dein.

<br>
<br>
