# LAB: Host your website in S3

AWS S3 par Static Website Hosting karna production level par ek bohot hi popular use-case hai. Isse aap apni HTML, CSS, aur JavaScript wali website ko bina kisi EC2 server ya database ke, bohot hi saste aur super-fast tareeqe se pure internet par live kar sakte hain.

Production environments mein jab hum S3 par website host karte hain, toh do cheezein compulsory hoti hain: Public Access open karna aur Bucket Policy lagakar duniya ko sirf files read karne ki permission dena (varna website khulegi hi nahi aur 403 Forbidden error aayega).

Chaliye, ek complete Production-Level Static Website Hosting Lab karte hain.

<br>
<br>

### Lab Prerequisites & Setup (Computer Par)

Apne computer par do files banayein jo hamari website ka kaam karengi:
- **File 1**: Naam rakhein ```index.html``` (Yeh aapka home page hoga). Notepad mein kholein aur yeh code paste karein:
```
<!DOCTYPE html>
<html>
<head>
    <title>Puneet Production Website</title>
    <style>
        body { font-family: Arial, sans-serif; text-align: center; margin-top: 100px; background-color: #f4f4f9; }
        h1 { color: #FF9900; } /* AWS Orange Color */
    </style>
</head>
<body>
    <h1>Welcome to My Production Website Hosted on AWS S3!</h1>
    <p>This website is serverless, highly available, and cost-effective.</p>
</body>
</html>
```

- **File 2**: Naam rakhein error.html (Agar koi galat link kholega toh yeh dikhega). Code paste karein:
```
<!DOCTYPE html>
<html>
<head>
    <title>Page Not Found</title>
</head>
<body style="text-align: center; margin-top: 100px;">
    <h1 style="color: red;">404 - Page Not Found!</h1>
    <p>Oops! The page you are looking for does not exist.</p>
    <a href="index.html">Go Back to Home</a>
</body>
</html>
```

### Step-by-Step Production Website Lab

**Step 1: Bucket Ke "Block Public Access" Switch Ko OFF Karein**:

Kyunki yeh website pure internet ko dikhani hai, hume AWS ka master safety switch band karna hoga.
- AWS Console mein **S3** open karein aur apni bucket ```meri-bucket-puneet``` par click karein.
- Upar diye gaye tabs mein se **Permissions** tab par click karein.
- Pehla section dikhega:**Block p ublic access (bucket settings**). Uske right side mein **Edit** button par click karein.
- **Block all public access** ke aage se tick hata (uncheck) dein.
- Niche **Save changes** par click karein aur pop-up mein ```confirm``` likh kar enter kar dein.

<br>

**Step 2: Public Bucket Policy Lagayein (Anonymous Read Access ke liye)**:

Sirf switch band karne se data public nahi hota. Hume bucket policy lagakar har anjaan internet user ko ```s3:GetObject``` (read-only) ki permission deni hogi. Iska matlab hai bucket users ko permission deti hai ki mere ander rakhi hui files aap dekh sakte ho.

- **Permissions** tab ke andar hi niche scroll karein aur **Bucket policy** ke **Edit** button par click karein.
- Niche diye gaye JSON code ko paste karein (Dhyan rahe, ```meri-bucket-puneet``` ko apne asli bucket name se badal lein):
```
{
    "Version": "2012-10-17",
    "Statement": [
        {
            "Sid": "PublicReadGetObjectForWebsite",
            "Effect": "Allow",
            "Principal": "*",
            "Action": "s3:GetObject",
            "Resource": "arn:aws:s3:::meri-bucket-puneet/*"
        }
    ]
}
```
- Sabse niche jaakar **Save changes** par click kar edin. Aapki bucket par ab ek orange color ka "Public" tag aa gaya hoga.

<br>

**Step 3: Static Website Hosting Feature Ko ON Karein**:

- Upar diye gaye tabs mein se is baar **Properties** tab par click karein.
- Page ke sabse niche (end tak) scroll kar lijiye. Wahan aapko aakhri section dikhega: **Static website hosting**.
- Right side mein **Edit** button par click karein.
- **Static website hosting**: Ise **Enable** select karein.
- **Hosting type**: Host a static website par hi check rehne dein.
- **Index document**: Yahan exact naam dalein hamari file ka: ```index.html```.
- **Error document**: Yahan dalein: ```error.html```.
- Sabse niche jaakar **Save changes** par click kar dein.

<br>

**Step 4: Website Files Ko Upload Karein**:
- Upar diye gaye **Objects** tab par wapas aayein.
- **Upload** par click karein aur apne computer se dono files (```index.html``` aur ```error.html```) ko select karke upload kar dein.

<br>
<br>

### Live Testing (Duniya Ko Website Dikhao)

- Wapas **Properties** tab mein jayein aur sabse niche **Static website hosting** wale section par scroll karein.
- Wahan aapko ek unique URL dikhega jise kehte hain **Bucket website endpoint** (Yeh URL aisa dikhega: ```http://amazonaws.com```).
- Us link par click karein!

**Boom**! 🎉 Aapki custom website live ho chuki hai aur poori duniya mein koi bhi is link se ise dekh sakta hai.

**404 Error Check**: Apne browser ke address bar mein S3 endpoint ke aage kuch bhi galat address type karke check karein (jaise ```/about-us```). Aap dekhenge ki aapka custom ```error.html``` page load ho jayega.
